# restaurant-billing-system (SQLite + DBeaver)
## 📌 Overview
A simple restaurant billing system built using SQLite and practiced in DBeaver.

## 🗂 Tables
- Customers
- Menu
- Orders
- OrderDetails

## ⚡ Features
- Insert and manage data
- Calculate tip percentage
- View top customers by tip

## 🛠 How to Run
1. Open DBeaver.
2. Connect to SQLite database.
3. Run `restaurant.sql` script.

## 🎯 Learning Outcome
Practiced SQL basics and advanced queries like JOIN and VIEW.
